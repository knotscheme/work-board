    04 依頼メモ

    依頼メモのテンプレート

    開発を頼む前に、この6つを埋めるだけで、見積もりが早く正確になります。サクアプ以外に相談するときにも使えます。

    【アプリの相談メモ】
1. 誰が使いますか？
　（例：ひとりでネイルサロンを営む人と、そのお客様）

2. いま何に困っていますか？
　（例：施術中に予約の電話に出られず、予約を逃している）

3. 最初にほしい機能は？（1つだけ）
　（例：空き時間から予約できる）

4. あとで足したい機能は？
　（例：カード決済、前日のLINEリマインド）

5. 似ているアプリ・サイトはありますか？
　（例：〇〇の予約画面のような感じ。スクショがあれば添付）

6. 予算と、使い始めたい時期は？
　（例：3万円まで・2か月後）
    05 AIプロンプト

    AIでアイデアを深める
    プロンプト10選

    ChatGPTやClaudeなどに、そのまま貼って使えます。どのプロンプトも、最初の「前提」の（ ）を自分の内容に書きかえてから使ってください。上から順に使うと、アイデアが少しずつ具体的になります。

    使い方のコツ・「前提」は1回書いたら、メモに保存して使い回すと楽です。

    ・答えが浅いと感じたら「もっと具体的に」「反対の立場から見直して」と続けて送ってください。
    01アイデアを「売れる1文」に磨く
    # 前提
・アイデア：（例：ひとりネイルサロン向けの予約アプリ）
・想定するお客さん：（例：自宅でひとりで営業しているネイリスト）

# あなたの役割
個人向けの小さなWebサービスを数多く立ち上げてきた事業開発の専門家として答えてください。

# やってほしいこと
1. 情報が足りない場合は、答える前に私に質問を3つまでしてください。
2. 「誰の・どんな困りごとを・いくらで解決するか」がわかる1文を、切り口を変えて5案作ってください。
3. 各案を「具体性」「困りごとの強さ」「お金を払う理由の強さ」で、それぞれ5点満点で採点してください。
4. いちばん強い案を選び、その理由と、まだ弱い点・言い直し案を書いてください。

# 条件
・あいまいな言葉（便利・効率化など）は使わず、場面が浮かぶ言葉にしてください。
・根拠のない数字は使わないでください。
